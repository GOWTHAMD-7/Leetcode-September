# LeetCode September 2026 🚀

> **30 days. One commitment. Show up every day.**

This repository documents a personal challenge I set for myself in **September 2026**:

**Code every single day for 30 days and commit my work to GitHub.**

The goal wasn't simply to maximize the number of problems solved. I wanted to test my ability to stay consistent with something I had chosen for myself — even on busy, tiring, or unmotivated days.

## 🎯 The Challenge

For September, my rule was simple:

* Code every day
* Spend at least **30–45 minutes** on problem solving
* Solve and commit LeetCode problems
* Don't break the streak

The challenge had one main purpose:

> **Build consistency through action rather than simply believing that I can be consistent.**

## 🧠 What I Learned

The biggest takeaway from this challenge wasn't the number **80**.

It was learning that consistency becomes much easier when the commitment is clear and small enough to be non-negotiable.

There were:

* outing days
* movie days
* Sundays
* tiring days
* days when I simply didn't feel like coding

But the minimum commitment remained.

I also learned that I don't need every goal I set to go perfectly in order to make progress. Some of the other habits I planned for September didn't last the entire month.

This one did.

That gave me something more valuable than a streak:

> **Evidence that I can commit to something and follow through.**

## 🔍 Beyond the Numbers

I'm trying to move away from measuring myself only by what I *think* I'm capable of.

Instead, I want to build evidence through the things I actually do.

This repository is one small piece of that evidence.

It represents:

**Commitment → Action → Consistency → Reflection**

The next step is to take that consistency beyond problem solving and put more time into:

One month at a time.
