LeetCode 2326 - Spiral Matrix IV

Approach:

Initialize an m x n matrix with 4 boundary pointers: is (top row), ie (bottom row), js (left col), je (right col).
Traverse the matrix perimeter-by-perimeter in spiral clockwise order:
- Left-to-right along row is, then increment is.
- Top-to-bottom along column je, then decrement je.
- Right-to-left along row ie (if is <= ie), then decrement ie.
- Bottom-to-top along column js (if js <= je), then increment js.
At each visited cell, assign head.val if head is not null and advance head = head.next; otherwise assign -1.
Return the filled matrix.

Complexity:

Time: O(m * n) visiting each cell of the matrix exactly once.
Space: O(m * n) to allocate the output matrix.

Key Takeaway:
Boundary pointer shrinking simulates spiral traversal cleanly, assigning default fallback values (-1) when the linked list is exhausted.
